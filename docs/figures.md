# Figure catalogue

All in [results/figures/](../results/figures/), regenerated by `python src/09_figures.py`.
Each is drawn from `results/*.json` or the processed tables, never from hand-typed numbers.

Titles state what is plotted. The interpretation is in [findings.md](findings.md) and belongs
in the thesis text, not on the figure.

## Three that carry the argument

**`b2_users_per_route`** — the distribution, in one bar.

**`b8_overlaid_routes`** — the same distribution geographically: dense corridors, distinct
complete routes.

**`c4_ceiling_vs_achieved`** — the share of test cases that were reachable at all.

## Design notes

Two colours: blue is the default, orange marks the single element a figure is about. Axes run
0–100% where the magnitude of a small value is the point, rather than auto-scaling. Gridlines
are solid hairlines; labels appear on endpoints and highlighted marks only.
